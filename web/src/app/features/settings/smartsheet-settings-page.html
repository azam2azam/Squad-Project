Where do these values come from?
  1. Access token — in Smartsheet, open Account → Personal Settings → API Access and generate a token. Use a service account with access to the sheets you want on the board, not a person's own login: when that person leaves, every linked board stops updating.
  2. API URL — leave it as https://api.smartsheet.com/2.0 unless your organisation is on a regional endpoint.
  3. Column mapping — a sheet is a spreadsheet, so unlike a Jira issue there is no universal notion of "done". Name the columns that carry progress and status; the defaults match Smartsheet's own project templates.
  4. Per board — open a board and paste its sheet id (in Smartsheet: File → Properties → Sheet ID). Boards without one are left alone.

The connection is read-only. This app never writes to your Smartsheet. The sync guide explains the suggest-versus-apply rule, which works the same way here.

Which columns to read

A sheet has no fixed shape, so the sync has to be told where to look. Progress is averaged from the percentage column when it exists; otherwise it is counted from the status column, and the board says which was used.

Test the connection

Makes a real call, so "not configured" can be told apart from "configured but the token is wrong". Give a sheet id to check the token's account can actually open it.

Automatic updates

With auto-apply off, Smartsheet only suggests — the board editor shows what the sheet says and the Product Owner accepts it. With it on, a background job writes progress and status to every linked board on the interval below. Sprint, blocker notes, risks and the squad roster are never touched.
