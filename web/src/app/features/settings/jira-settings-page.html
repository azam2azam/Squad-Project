Where do these values come from?
  1. Jira URL — your company's Jira site, e.g. https://yourcompany.atlassian.net. It must be https.
  2. Email — the Atlassian account the board reads as. Use a service account with read access to the projects you want on the board, not a person's own login: when that person leaves, the connection would break.
  3. API token — create one at id.atlassian.com/manage-profile/security/api-tokens while signed in as that account. Paste it below; it is encrypted before it is stored and is never sent back to a browser.
  4. Per board — open a board and set its Jira project key (e.g. PIRT). Boards without a key are left alone.

The connection is read-only. This app never writes to your Jira. Read the full guide for how the figures are worked out and what a sync will never overwrite.

Automatic updates

With auto-apply off, Jira only suggests figures — the board editor shows what Jira says and the Product Owner accepts it. With it on, a background job writes sprint, progress and status to every linked board on the interval below. Blocker notes, risks and the squad roster are never touched either way.
